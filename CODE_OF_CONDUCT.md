# Code of Conduct

## Our standard

Contributors should create a welcoming, respectful, and technically constructive community. Be considerate, accept good-faith feedback, focus criticism on ideas and code, and respect privacy.

Unacceptable behavior includes harassment, discrimination, threats, publishing another person's private information, sexualized attention, deliberate disruption, or sustained bad-faith conduct.

## Scope

This standard applies in repository issues, pull requests, discussions, and other project spaces.

## Enforcement

Report conduct concerns privately to the repository maintainers through GitHub. Maintainers may edit or remove content, close or lock discussions, reject contributions, or temporarily or permanently restrict participation when necessary.

Enforcement decisions should protect affected participants' privacy and be proportionate to the behavior.
